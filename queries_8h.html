const char * bestiary_query ( char * line,
Bestiary * bestiary,
RecipeBook * recipeBook )

Handles bestiary-related queries for effectiveness and potion formulas.

Supports:

  • "effective against <monster> ?" → Lists effective items, alphabetically.
  • "in <potion> ?" → Lists ingredients in the potion, sorted by quantity and name.

Returns:

  • Formatted result string (e.g., "3 Vitriol, 2 Rebis\n")
  • "No knowledge of <monster>\n" or "No formula for <potion>\n" if unknown.
  • "INVALID" for malformed input.
Parameters
lineInput query string (mutable, ends with '?').
bestiaryBestiary data with monster weaknesses.
recipeBookKnown potion formulas.
Returns
Dynamically allocated result string, or static string.

int compare_recipe_ingredients_by_quantity ( const void * a,
const void * b )

Comparison function for sorting recipe ingredients.

This function compares two Ingredient structures, primarily by quantity in descending order. If the quantities are equal, it compares the ingredient names in lexicographical (alphabetical) order.

Parameters
aPointer to the first Ingredient.
bPointer to the second Ingredient.
Returns
Negative value if 'a' should come before 'b', positive if 'a' should come after 'b', zero if they are considered equal.

Inventory * inventory,
PotionInventory * potionInventory,

Processes inventory queries for ingredients, potions, or trophies.

Supports:

  • "<type> ?" → Lists all items of given type, sorted alphabetically.
  • "<type> <name> ?" → Returns quantity of the specified item.

Valid types: ingredient, potion, trophy. Returns:

  • Formatted result string (e.g., "3 Rebis, 1 Vitriol\n")
  • "0\n" if item not found, "None\n" if inventory is empty, or "INVALID" for bad input.
